== Description ==

Skeleton Blog is a small, clean blog theme made by Mehran Shahmiri. It is built on Skeleton (http://getskeleton.com/), the responsive CSS boilerplate by Dave Gamache, and follows the look of the getskeleton.com site: a narrow centered column, a thin sticky navigation bar, a big calm hero, and post lists with featured images.

* Hero on the home page (title, tagline, button and optional header image, all editable in the Customizer)
* Layout option: single column or content with a right sidebar
* Colour scheme: light, dark, or follow the visitor's device, plus an accent colour picker and a custom background
* Page templates: Full width, and Landing page (no title)
* Front page template (static page with the hero and latest posts), author archive, attachment pages
* Post format styles, social links menu, four block patterns, theme.json (editor palette, font sizes, widths), starter content
* Live preview of the hero, site title and footer text in the Customizer
* Sticky navigation bar with one level of sub-menus (CSS only)
* Post list with featured image, date, reading time, category and excerpt
* Single post, page, archive, search and 404 templates
* Threaded comments, post navigation, author box
* Footer menu and a footer widget area
* Custom logo, translation ready, accessibility ready (skip link, focus styles, ARIA labels)
* Block editor support with matching editor styles
* The Raleway font is bundled, so the theme makes no requests to third parties
* No JavaScript of its own

== Installation ==

1. In WordPress go to Appearance > Themes > Add New > Upload Theme and choose skeleton-blog.zip, or copy the skeleton-blog folder into wp-content/themes.
2. Activate the theme.
3. Appearance > Menus: create a menu and assign it to "Primary menu" (and optionally "Footer menu").
4. Appearance > Customize > Skeleton Blog: edit the hero text, button, footer text and options.

== Frequently Asked Questions ==

= Does it need JavaScript? =
No. The only script it ever loads is WordPress core's comment-reply script, and only on posts with threaded comments.

= Can I remove the footer credit? =
Yes. Appearance > Customize > Skeleton Blog > "Show the theme credit in the footer".
